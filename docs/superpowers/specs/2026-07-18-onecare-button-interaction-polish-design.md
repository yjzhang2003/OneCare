# OneCare 文字按钮交互统一设计

## 状态与优先级

本规格记录 2026-07-18 对 OneCare 首页文字按钮的补充规则。它补充并覆盖 `2026-07-18-onecare-hisense-showroom-redesign-design.md` 中与按钮箭头、按钮内容布局和悬停位移冲突的描述。

## 目标

修正“查看四个视角”和页头“飞书登录”的悬停动效，使它们与 Hero 中“使用飞书登录”的纯颜色反转反馈一致；同时建立“文字按钮不带箭头、文字始终居中”的长期规则。

## 交互规则

### 1. 统一颜色反转

- `查看四个视角`、页头 `飞书登录` 和 Hero `使用飞书登录` 只允许颜色、背景色和边框色在 `180ms ease` 内过渡。
- 三个按钮悬停后统一变为白色背景、黑色文字；按下状态使用 `#E7E7E7` 背景。
- 不允许 `translate`、缩放、箭头移动、间距拉伸或内容位移。
- 键盘 `focus-visible` 继续保留双层清晰焦点，不以悬停状态替代焦点状态。
- `prefers-reduced-motion: reduce` 下取消过渡时长。

### 2. 文字按钮内容

- 所有药丸形文字按钮只显示可读文字，不显示 `↗`、`↓`、`↑` 或其他装饰方向符号。
- 使用 `inline-flex`、`align-items: center`、`justify-content: center` 和 `text-align: center` 保证文字在可点击区域内水平、垂直居中。
- 左右内边距必须对称；不得为曾经存在的图标预留空白。
- 已登录状态的 `工作台`、`进入工作台` 复用同一结构，不增加方向图标。

### 3. 返回顶部

- 页尾原有圆形上箭头入口改为文字药丸按钮 `返回顶部`。
- 保留 `href="#top"` 和可访问名称，不改变滚动目标。
- 返回顶部按钮沿用青绿底黑字，悬停时使用白底黑字的同一颜色反转反馈。

## 组件范围

- `src/features/showcase/components/site-header.tsx`：删除页头 CTA 箭头。
- `app/landing-content.tsx`：删除两个 Hero CTA 箭头包装。
- `src/features/showcase/components/site-footer.tsx`：将上箭头改为 `返回顶部` 文字。
- `app/globals.css`：统一颜色过渡、居中、按下状态、减少动态状态和返回顶部药丸样式。

不修改导航链接、四视角 Tab、认证 URL、登录逻辑、页面内容结构和生产部署配置。

## 验收标准

1. 页面源码中的首页文字按钮不包含 `↗`、`↓`、`↑` 或 `.action-arrow`。
2. `查看四个视角`、页头登录 CTA 和 Hero 登录 CTA 的计算样式均为居中布局。
3. 三个 CTA 悬停时计算背景色为 `rgb(255, 255, 255)`、文字色为 `rgb(0, 0, 0)`，且 `transform` 为 `none`。
4. 页尾存在文字为 `返回顶部`、目标为 `#top` 的药丸按钮。
5. 桌面端和移动端无按钮文字偏移或横向溢出。
6. 单元测试、Lint、类型检查、生产构建和浏览器交互验收通过后，只更新非生产 Vercel Preview。

## 原型边界

本改动只统一视觉和微交互，不改变飞书登录是否可用、服务方案能力或任何生产业务状态。
